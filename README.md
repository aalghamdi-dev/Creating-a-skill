# Week 4 — Using & Building Claude Skills

This repo holds my daily tasks for Week 4, which is about understanding, using, and building Claude Skills.

## Overview

| Day | Focus | Task |
|---|---|---|
| 1 | What is a Skill | Analyze three existing Claude Skills — explain when each triggers and what problem it solves |
| 2 | Using Existing Skills | Run several existing Claude Skills with different inputs and compare their outputs and behavior |
| 3 | The SKILL.md Structure | Design a folder layout and write a first version of a SKILL.md file |
| 4 | Build Your Own Skill | Author a custom skill with its own SKILL.md and verify it works |
| 5 | Test & Chain Skills | Chain two skills into one workflow, test it, and improve it through peer review |

## Goal

By the end of the week, have a working custom Claude Skill, tested and chained with another skill into a small multi-step workflow.
